# Sistema de Gestão de Currículos

Projeto desenvolvido com Next.js, Tailwind CSS, React Hook Form, Yup e Sonner.

## Funcionalidades

- Cadastro de currículos
- Busca em tempo real
- Página dinâmica de detalhes
- Upload de imagem
- Experiências profissionais dinâmicas
- Validação de formulário
- Toasts de sucesso e erro
- Persistência com localStorage
- Exclusão de currículos
- Layout responsivo

## Tecnologias Utilizadas

- Next.js
- React
- Tailwind CSS
- TypeScript
- React Hook Form
- Yup
- Sonner

## Como executar o projeto

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Abra no navegador:

```txt
http://localhost:3000
```

## Rotas
